# Human input to the project

The project was run by AI agents (a PI agent in Claude Code coordinating Claude Opus 5.5 / Claude
Sonnet 5.5 sub-agents; see [../AGENT_SETUP.md](../AGENT_SETUP.md)). The only human input was the
messages below, reproduced verbatim and in order (line breaks as sent). The human did not write
code, choose methods, or edit results.

| # | file | message |
|---|---|---|
| 0 | [../PROMPT.md](../PROMPT.md) | initial project prompt (verbatim; one local file-system path redacted) |
| 1 | [01_questions.md](01_questions.md) | three questions about the results (dimers, GPU use, remaining ideas), after the first final summary |
| 2 | [02_extension.md](02_extension.md) | time extension (decision D19 in the research tree) |
| 3 | [03_finalize.md](03_finalize.md) | "are we done?" |
| 4 | [04_manuscript_and_repo.md](04_manuscript_and_repo.md) | request for the manuscript and this repository (decision D20) |

In addition, the session was restarted twice by the environment ("Continue" messages without
content); the human did not otherwise intervene. Agent-to-agent briefs were not archived as files.
The agents' responses and decisions are in
[../docs/research_record/RESEARCH_TREE.md](../docs/research_record/RESEARCH_TREE.md) (decision log D0–D20).
